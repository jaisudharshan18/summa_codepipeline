About This Pipeline

Continuous Integration and Continuous Deployment (CI/CD) automates software delivery. Instead of manually uploading files to servers, pipelines run automated tests and deploy on every git commit.

🔄 Continuous Integration (CI)

Developers merge code frequently into the repository. Automated jobs test the code to catch syntax issues, missing files, or broken links before deployment.

🚀 Continuous Deployment (CD)

Once tests in CI pass successfully, the CD phase automatically deploys the updated code to production or hosting environments like GitHub Pages.

📝 YAML Configuration

Pipelines are configured in human-readable YAML syntax. Look at .github/workflows/ci.yml to see triggers, jobs, and steps.

🛡️ Automated Checks

Our pipeline automatically verifies that index.html exists and confirms your "Hello" greeting is present before going live.
